台账与复盘

台账是判重的唯一依据，也是复盘唯一的证据。没写进台账的报名，等于没报。

4.0开工工具（本地运行 · 不联网）

台账只在你本机解析，不上传。每天开工顺序：载入台账 → 查重 → 导出集合 → 再去搜帖。

选「探店报名台账_日期.md」；下次打开自动恢复
尚未载入台账
品牌能在台账里对上就是「已报过」，对不上才进六道门 
载入台账后点「生成集合」，得到全部报过的品牌；搜帖前先拿这份对照。
填好品牌后点「生成表格行」，或在品牌框直接按回车。

4.1文件落点（实际在用的两份）

文件写什么规则
探店报名台账_日期.md每报一家追加一条，17 列顺序固定；含通过待办、已完成批次、跳过/判重清单、待补段批次按天编，三重键「批次+品牌+活动名」防重复追加
探店复盘.html当天评论条数、有效家数、误投/跳过清单、风控记录、待补项误投和跳过必须写，不能只写好数
写回前先备份 每次写回前先复制一份带 _bakMMDD 的备份；写完核对条数，别覆盖掉历史批次。判废的也记进台账，状态写「已取消（原因）」，原因要具体。

4.217 列固定顺序（不许改）

台账字段顺序 · 复制即用 
日期｜批次｜序号｜标准品牌名称｜产品名称｜招募活动名称｜招募发布时间｜招募来源｜店名｜品类｜类型｜是否中签｜当前状态｜是否已收货｜是否已体验｜是否已发布｜备注
字段填什么注意
日期 / 批次 / 序号2026-11-16｜第19批·11-16武汉免费体验/探店置换｜1、2、3…批次按天编，序号当天从 1 起
标准品牌名称品牌名，不带门店后缀判重主要看这个
产品 / 活动名称给的东西、活动名如「双人餐」「1000 位试吃官」
发布时间 / 来源几天前 / 小红书搜索超 7 天的不该出现在这里
店名帖子标题原文不改写、不缩写
品类中餐 / 火锅烧烤 / 自助小吃 / 饮品 / 甜品 / 零食 / 护肤寄样…和品类排序用同一套词
类型到店置换 / 到店领取 / 寄样试用 / 线下异地 / 非招募异地线下也要记，标「已取消」
是否中签 / 当前状态未 / 是｜已报名、待赴约、已取消（原因）取消必须写原因
收货 / 体验 / 发布未 / 是这三项是复盘的分母
备注笔记 ID、发布地、特殊要求、瑕疵、待补项不写情绪

4.3判重口径（与 02 页一致）

  • 三重比对：店名、标准品牌名称、招募活动名称，三个都对一遍。
  • 同品牌跨门店视为重复；标题前 6–20 字、正文前 300 字兜底；评论区有本人留言即报过。
  • 每天开工先把台账里的品牌、标题拉成判重集合，再去搜帖。

4.4一周看四个数

指标怎么算看到不对怎么办
报名数当天新增条数，去掉取消的连续两天不到 20，换关键词组，别死磕同一屏
中签率中签数 ÷ 报名数低于一成，回头看是不是品类太偏或粉丝门槛卡住
到店完成率已体验 ÷ 待赴约低于一半，说明约了没去，压缩一天的家数
出稿率已发布 ÷ 已体验出稿为 0 就是白跑，出稿是唯一产出
别拿报名量当成绩
  • 报了 300 家、一篇没发，等于零。
  • 复盘只认三样：去成了几家、发了几篇、有没有带来真实合作。

4.5可复制指令

指令 A｜把今天的报名写进台账 
把今天这批发进台账，一条记录不要漏字段。

【字段顺序，固定】
日期｜批次｜序号｜标准品牌名称｜产品名称｜招募活动名称｜招募发布时间｜招募来源｜店名｜品类｜类型｜是否中签｜当前状态｜是否已收货｜是否已体验｜是否已发布｜备注

【填写要求】
- 日期写 2026-11-16 这种格式，批次写成「第N批·MM-DD武汉免费体验/探店置换」。
- 店名用帖子标题原文，不要改写、不要缩写；备注记笔记 ID 和瑕疵。
- 类型：到店置换 / 到店领取 / 寄样试用 / 线下异地 / 非招募。
- 判废的也写进去，状态写「已取消（原因）」，原因要具体：异地线下、同品牌重复、只有标签、抽奖帖、待核。
- 写回前先备份一份 _bakMMDD。

写完告诉我：今天总条数、有效报名几家、取消几家、分别是什么原因。
指令 B｜一天收工复盘 
今天收工，按四个数给我复盘，不要写成长篇。

1. 报名：有效几家，比 20 差多少，差在哪（关键词榨干 / 门槛不够 / 时间不够）。
2. 中签：今天新中签几家，是哪几家，有没有时限。
3. 到店：多少家待赴约，最早哪家到期，今天该回谁的消息。
4. 出稿：这周发了几篇，还有几张图压着没发。

最后给我明天第一件事做什么，一句话，不要列清单。没报够就如实说，不拿旧帖外地帖凑数。
