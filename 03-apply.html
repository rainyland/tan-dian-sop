四件套报名

四件套缺一件就不算报上。每家报完都要在页面上看见证据，看不见就当没做。顺序固定：关注 → 点赞 → 收藏 → 评论。

3.1四个动作，每步先读状态再点

  • 关注：认 .follow-button 文案，显示「关注」才点；显示「已关注」说明本来就关注，跳过，别点成取消。离屏假按钮 note-detail-follow-btn 点了没反应时，改用 JS 点 button.follow-button。
  • 点赞：看 .like-wrapper 是否含 like-active；已激活就跳过，没激活再点，别把赞点掉。
  • 收藏：先记下收藏数 → 点击 → 数字 +1 为成功；数字 -1 说明本来就收藏着、被点掉了，必须再点一次恢复。收藏按钮没有「已收藏」字样，只能靠数字变化判断。
  • 评论：先清空输入框草稿，再贴话术；发送后清空输入框，确认评论区能看见自己的评论。
收藏最容易出错
  • 点完数字变小，等于把之前的收藏取消了，立刻再点一次补回来。
  • 按钮被浮层/弹窗遮挡、JS 点击无效时，不要反复硬点；记下「收藏待补」，在无遮挡环境补点。

3.2评论话术（唯一版本，逐字使用）

不要改，也不要加表情。部分招募要求另写「报名」两字或发主页截图，按对方要求补在话术之后。

报名话术 · 逐字复制 
报名！武汉光谷在读女生，美食探店博主，真实体验认真写测评，坐标武汉随叫随到～爱吃会拍，出片快不拖更，口味描述真实不尬吹
  • 要求私信的：评论照常发，私信正文由本人自己发，助手不代发。
  • 要求发主页截图的：先按对方要求发图文，再贴话术。
  • 寄样/个护/茶饮/烘焙/水果类不套「爱吃会拍」餐饮话术：按帖内招聘要求写留言（指定句如「想试吃+产品名」「我要报名」「我要当体验官」，或分享常喝奶饮/口味期待），不提"爱吃会拍"。
品牌指定留言句 · 替换门店名后逐字复制 
我想成为【品牌名+门店名】新品品鉴官！
  • 招募帖正文明确要求「留言+品牌名/门店名」的，用这句，不要贴通用话术。
  • 示例（按帖内实际门店替换，不改句式）：我想成为南棠馆群光广场店新品品鉴官！／我想成为九十九里棠武商梦时代店新品品鉴官！
  • 没指定留言格式的，一律回到上面唯一通用话术，不自创称呼、不加表情。

3.3评论框填不进去时的技术写法

评论框是 <p contenteditable>，常被遮罩挡住，普通 type 进不去。

  • 先 focus() → execCommand('selectAll') → execCommand('delete') 清空草稿。
  • execCommand('insertText', false, 话术) → dispatchEvent(new InputEvent('input'))。
  • scrollIntoView({block:'center'}) 后点 button.btn.submit。

3.4怎么确认真的发出去了（三条都要过）

  • 评论数 +1：发前记一次，发完再记一次，.chat-wrapper .count 必须多 1。
  • 输入框已清空：草稿还留在框里，页面正文也会出现话术，会造成假阳性。
  • 评论区能看见自己：显示「小呆呆不呆呆」+ 话术 +「刚刚」；评论区只加载一部分，翻不到自己就以前两条信号为准。
三条都过才算报上；任一信号模糊，记「未确认」，不盲目重发。同一条帖只发一次评论，避免留下两条一样的。

3.5节奏与风控红线

红线实测口径应对
单家间隔15 秒内必触发；20–30 秒相对安全固定 20–30 秒，快只会更慢
单日评论量45 条左右已是上限；11-15 发 49 条当天跳验证单日 ≤ 45，目标 20 家就收
连续换词连搜 2 个词即可能跳 captcha一次一个词，两个词之间停一下
跳验证 / 登录搜索页直接跳验证码，或结果全空立刻停手，交回本人验证；不刷新、不换词、不换号、不换数据源
搜索页空壳卡片数 0 但地址正常停手，重新单次 navigate 同一地址再看；仍空就收工
设备离线 / 断线环境掉线、浏览器会话丢失，动作结果未确认不切云主机重放、不重复点；恢复后先核验关注/赞/藏/评论当前态，缺什么补什么，已做的不重做

3.6可复制指令

指令 A｜报一家，回一条结果 
帮我报这一家，四件套缺一件就算没成，最后给我一行结果。

【顺序】
1. 关注：按钮文案是「关注」才点；已是「已关注」就跳过。
2. 点赞：已赞高亮就跳过，不要点成取消。
3. 收藏：先记数字，点完 +1 算成；数字 -1 说明本来就收藏过，立刻再点一次补回来。
4. 评论：先清空输入框草稿，再贴话术，发送后清空输入框。

【话术逐字用，不要改】
报名！武汉光谷在读女生，美食探店博主，真实体验认真写测评，坐标武汉随叫随到～爱吃会拍，出片快不拖更，口味描述真实不尬吹

【验收】
- 评论数发前发后各记一次，必须 +1。
- 输入框已清空，评论区能看到「小呆呆不呆呆」+ 话术。
- 三条都过才算报上，否则写「未确认」。

【节奏】
每家间隔 20–30 秒。出现验证码、跳登录页、页面空壳，立刻停手告诉我。

结果格式：帖名｜关注｜点赞｜收藏（数字变化）｜评论数变化｜是否确认成功｜没成功的原因
