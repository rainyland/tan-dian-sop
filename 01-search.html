01 / 05　SEARCH

搜帖与挖新

同城招募帖总量有限，一个词通常只回 20 条左右、滚动不加载。能不能凑够名额，靠换词的广度，不靠刷得勤。

1.1进场规矩

  • 一律从搜索页进，地址固定带时间倒序：/search_result?keyword=关键词&source=web_explore_feed&sort=time_descending&type=51。不加 sort=time_descending 等于看老帖。
  • 点卡片封面进详情；封面裂了就点卡片标题链接（带 xsec_token）。不要把笔记链接直接粘到地址栏——直连缺 token 容易 404。
  • 一次只搜一个关键词；连续换两个词就停一下，避免跳验证。
  • 每个词只看第一屏约 20 条，想看新的只能换词，不靠滚屏。
  • 出现空结果、验证码、跳登录页，立刻停手交回本人，不刷新重试、不换词、不换号。

换词节奏
  • 一个词能挖出 3 家以上新的，就在这个词上加地点或品类继续拆。
  • 同城线榨干后再走寄样线，寄样池子深、回复慢，当底仓慢慢滚。

1.3卡片上先筛一层（不进详情）

  • 看标题：抽奖、活动汇总、免费遛娃、已结束、避雷攻略，直接不进详情。
  • 看时间：只认 7 天内。按「X 天前 / MM-DD」判断；作者昵称里带「今天」别误当日期。
  • 看店名：和台账店名撞上前 6 个字，跳到下一条。
  • 看发布地：卡片右下角带广东、上海、浙江等，先当外地帖，进详情再确认有没有寄样。
容易点错的坑
  • 卡片索引和封面不是一一对应，按顺序点会错帖；要按链接里的笔记 ID（explore|search_result/<12位hex>）对。
  • 标题串帖会缓存，仅凭标题判断不够；进详情后还要核对作者和正文首段。

1.4页面卡住时的兜底手法（实测）

卡片、封面、抽屉偶尔加载失败，先按下面顺序恢复，仍不通就记「待核」，不硬点、不直连。

卡点现象兜底做法
封面图批量 broken 卡片框在、封面图裂，坐标点封面进不了抽屉 刷新搜索页等 2–4 秒让 CDN 恢复；仍裂就用 JS 点卡片里的标题链接 a[href*="/search_result/"]，绕开封面直接打开带 token 的详情抽屉
卡片被浮层遮挡 点坐标报目标被遮挡（OBSCURED） 先 scrollIntoView 把卡片滚到视口中部，再按链接里的笔记 ID 定位；不靠封面坐标硬点
直连笔记链接 404 把 explore/<id> 粘地址栏打不开 笔记必须从搜索页卡片进抽屉；直连链接在未登录态/缺 xsec_token 时 404，不要据此判帖失效
抽屉正文读不到 抽屉未展开，页面文本只剩列表标题 优先读抽屉内 .note-detail / .detail-container / #detail-desc / .note-text 的正文；抽屉没弹就重进一次，仍空记「待核」
验证码 / 扫码 / 登录拦截 搜索跳二维码、身份验证页或结果全空 立刻停手交回本人：不刷新、不换词、不换号、不换数据源；本人验证通过后复查页面再继续

1.5可复制指令

指令 A｜按关键词批量搜帖（只搜不报） 
帮我在小红书上按关键词搜探店招募，一个词只给我搜索结果第一屏，不要自己编帖子。

【搜索方式】
- 从搜索页进：https://www.xiaohongshu.com/search_result?keyword=关键词&source=web_explore_feed&sort=time_descending&type=51
- 点卡片封面进详情，不要把笔记链接直接粘到地址栏。
- 一次只搜一个词，同一个词不要反复搜；连换两个词就停一下。

【每个词给我一张卡片清单】
标题｜作者｜发布时间（几天前或具体日期）｜发布地｜是否 7 天内｜标题里有没有抽奖/汇总/已结束字样｜笔记 ID

【先筛掉再给我】
- 发布时间超过 7 天。
- 标题是抽奖、活动汇总、遛娃攻略，不是品牌招募。
- 发布地不在湖北，且正文没写寄样/快递/邮寄/包邮。

不要替我点进去报名，只做搜帖这一步。
