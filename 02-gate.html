过门与判重

一条帖进详情，先按顺序过六道门；任意一道卡住直接退出。全过门再判重，最后才按品类排先后。

账号：小呆呆不呆呆 · 小红书号 Q19671165372 166 粉 · 382 关注 · IP 湖北 · 坐标武汉光谷 2025 级大二在读女生 · 探店置换口径

2.1六道门（按顺序过）

门过门条件卡住就跳过的情形
1 时间 发布在 7 天内 8 天前、上月发的；正文写「已收官 / 已截止 / 名额已满」；正文有效日期与发布时间矛盾（如 5 天前发布却写「即日起至 8 月 9 日」）属模板未更新，记待核不投
2 钱 全程零成本 押金、垫付、先买后返、团购、优惠券、付费合作、招商加盟、招募代理、返现；先尝后买、关注送小样、发笔记才领伴手礼/券，属促销不属免费置换；要求先在海外/旗舰店购买指定链接产品再返；要求加入福利群/活动群才参与抽选（助手不代加群）
3 地点 武汉到店；外地只接写清寄样/快递/邮寄/包邮的 外地线下到店且没写寄样；境外、港澳台、跨境
4 人群 招女生 / 素人 / 不限人群 只招男士、宝妈、婴童、孕妇、宠物专用品、限定某校学生
5 粉丝/渠道门槛 不要求粉丝数或点评等级，或门槛当前账号能达到 千粉 / 500 粉 / 300 粉以上、大众点评 V 级、要主页往期作品且当前拿不出——跳过，不硬蹭；要求晒本人已有实拍素材（挂耳冲泡图、穿搭照、出镜实拍）当前没有，也跳
6 正文质量 去掉标题后正文 ≥ 40 字，有实质内容和报名入口 只有标签和空壳；纯菜品介绍、个人日记、攻略吐槽；互赞积赞、互勉约拍；纯带货商品帖（标售价、已售，无报名入口）；明星应援标签帖；正文/海报没写清是否包邮、是否关注、门槛不清的，不硬投记待核
过门顺序提示
  • 先看时间，再看钱。多数帖死在第二道——写着「免费」，细则里要买券。
  • 第三道门最容易看走眼：「武汉」出现在标题，门店却在外地。
  • 第五道是实测高频卡点：166 粉，近半合格帖死在千粉 / 500 粉 / 2000 粉 / 点评等级门槛上，看到就直接跳。

2.2判重：报过的一个都不能再报

判重集合从台账现算，每天开工先加载；同品牌跨门店也算重复。

  • 品牌比对：标准品牌名、去括号核心词、去城市前缀、店名去地址后缀；同品牌跨店（如两家瓦伦丁）算同一家。
  • 标题比对：招募活动名归一化（去空格符号）后取前 6–20 字比对，拦「同一帖换个词又冒出来」。
  • 正文兜底：进详情取正文前 300 字再过一遍；两字小店名要拆词比，不能整串比。
  • 评论区复核：评论区已有本人「武汉光谷在读女生 / 小呆呆不呆呆」留言，说明报过了，跳过。
  • 两处复核：卡片阶段先用卡片文字过一遍；进详情后用正文再过一遍。
  • 命中即换下一张卡，不凑数。宁可当天只报几家，也不拿报过的凑名额。
白名单（不算品牌，避免误杀） 商圈词（光谷 / 江汉路 / 楚河汉街 / 万松园 / 街道口 / 徐东 / 昙华林 / 武商梦时代 / 万象城 / 恒隆 / 群光 / 永旺 / K11 / 武汉天地）与通用品类词（探店招募 / 体验官 / 新店 / 试营业 / 打卡 / 火锅 / 奶茶 / 咖啡 / 甜品）不进判重。

2.3实测排除清单（看着像招募，实际不是）

这些类型这两天反复出现，进门看清性质就跳，不要被标题里的「免费 / 试吃 / 招募」带过去。

类型识别特征结论
招聘 / 兼职 / 摊主招募招销售、帮工、出摊摊主；要经验、要连续到岗、小窗发自荐简历；给摊位或时薪补贴排除，不是探店置换
市集促销 / 先尝后买现场免费试吃但先尝后买；关注送小样、发笔记领伴手礼/优惠券，本质促销排除，不算零成本置换
活动 / 抽奖汇总买一送一、撕杯抽奖、券包攻略、本周活动合集、遛娃清单；汇总多条活动，无单店招募入口排除
医美 / 面部模特面部美学、皮肤管理模特、出镜素人招募，非餐饮、非普通护肤体验排除
收券 / 找搭子帖「收自助券」「蹲个搭子」「谁有券」，是个人求购/结伴，不是品牌招体验官排除
个人日记 / 攻略 / 避雷消费记录、打卡测评、避雷吐槽、经验分享，无报名入口和名额排除
中奖晒帖 / 已收官中奖者晒结果、「已结束 / 名额已满 / 已抽完」；正文日期与发布时间矛盾、模板未更新排除或记待核，不投
进群抽奖 / 群内公布「加福利群/活动群，群里随机抽、群内公布名单」，须本人进群排除，助手不代加群
先购买指定链接要先在海外/旗舰店下单指定产品，凭订单截图私信返样，非零成本排除，属先买后返
要本人已有素材评论区晒挂耳冲泡图、穿搭照、出镜实拍，要求自带成品内容排除，当前无素材不硬蹭
评论须@一位好友规则要求评论区@指定/任意好友参与，账号无可@对象排除，不编造账号、不硬@
邮费自理 / 到付产品免费但要自付 5 元邮费/到付，非纯零成本排除，不垫邮费
限外地同城到店只送某城市门店自提/到店（如青岛万达），武汉不送、无寄样排除，外地只接全国包邮寄样
纯带货商品帖 / 应援帖正文标售价、已售，全是产品介绍无招募入口；或全是明星话题标签、无规则排除，不是体验官招募

2.4过了门，按品类排先后

排序只按一条：能不能写出差异、值不值得跑一趟。当前主攻餐饮吃饭。

顺序品类为什么排这个位置
1中餐正餐 / 融合菜 / 湖北菜当前主攻。客单高，拍菜单和菜品最出片。
2火锅 / 烧烤 / 串串同城供给多，翻台快，约得上、出片稳。
3自助 / 面馆小吃 / 大排档门槛低、反馈快，用来补足当天家数。
4饮品咖啡 / 酸奶甜品最容易约上，穿插在正餐之间跑。
5烘焙甜点 / 食品零食出图轻，到店和寄样都有。
6护肤寄样 / 水果生鲜周期长、要等快递，排最后；同城线榨干后作为底仓顺带报。

2.5可复制指令

指令 A｜一条帖过门判重 
我把这条招募帖的正文贴给你（或截图给你），按六道门逐条判，最后只给「报 / 不报」和一个理由，不要长篇分析。

1. 时间：发布几号？是否 7 天内？有没有写已收官、已截止、名额已满？
2. 钱：有没有押金、垫付、先买后返、团购、优惠券、付费合作、招商加盟、返现？
3. 地点：武汉到店，还是外地？外地写了寄样/快递/邮寄/包邮吗？
4. 人群：招女生素人，还是只招男士、宝妈、婴童、孕妇、宠物专用？
5. 门槛：有没有要求千粉/500粉/300粉/2000粉、点评等级、往期作品？当前 166 粉够不够？
6. 正文质量：去掉标题还有没有 40 字以上实质内容和报名入口？

再判重：品牌、标题前 6–20 字、正文前 300 字、评论区有没有本人留言。

结论格式：
【报 / 不报】｜卡在第几道门｜一句话理由｜品类排序第几位｜是否与台账重复
指令 B｜一批帖排优先级 
这批帖子都过了六道门、也不重复，帮我按品类排先后，一天最多 20 家。

排序优先级：中餐正餐 → 火锅烧烤串串 → 自助/面馆小吃/大排档 → 饮品咖啡甜品 → 烘焙零食 → 护肤寄样/生鲜。
同城线先排，寄样线放在同城之后当底仓。

输出一张表：帖名｜品类｜武汉到店还是寄样｜建议排第几｜一句话理由（能不能写出差异、要不要跑一趟）。
排不进前 20 的放「候补」，不要硬塞进当天名额。
